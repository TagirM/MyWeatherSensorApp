# MyWeatherSensorApp

## Описание
MyWeatherSensorApp — это приложение, построенное на основе Spring Boot, которое обеспечивает функциональности для 
регистрации датчиков и добавления данных о погоде. Приложение состоит из 21 класса и 4 интерфейсов, которые 
взаимодействуют для обработки данных о сенсорах и метеорологических измерениях.

## Структура проекта

### Основной класс приложения
- `SpringRestMyappApplication`: Запускает приложение Spring Boot.

### Контроллеры
- `MyRESTControllerSensor`: Обрабатывает запросы связанных с регистрацией сенсоров.
- `MyRESTControllerWeatherData`: Обрабатывает запросы на добавление и получение метеорологических данных.

### DAO
- `SensorRepository`: Определяет методы для работы с данными о сенсорах.
- `WeatherDataRepository`: Определяет методы для работы с метеорологическими данными.

### DTO
- `SensorDTO`: Объект передачи данных для сенсора.
- `WeatherDataDTO`: Объект передачи данных для метеорологических измерений.

### Сущности
- `Sensor`: Представляет сущность сенсора.
- `WeatherData`: Представляет сущность метеорологических данных.

### Сервисы
- `SensorService`: Интерфейс для сервиса работы с сенсорами.
- `SensorServiceImpl`: Реализация сервиса для работы с сенсорами.
- `WeatherDataService`: Интерфейс для сервиса работы с метеорологическими данными.
- `WeatherDataServiceImpl`: Реализация сервиса для работы с метеорологическими данными.

### Валидаторы
- `SensorValidate`: Валидатор для проверки датчиков.
- `WeatherDataValidator`: Валидатор для проверки метеорологических данных.

### Исключения
- `GlobalExceptionHandler`: Обрабатывает глобальные исключения, возвращая соответствующие статусы HTTP.
- Классы исключений:
    - `NotSaveSensorException`
    - `SensorExistException`
    - `SensorNotCreatedException`
    - `SensorNullException`
    - `WeatherDataNotCreatedException`
    - `WeatherDataNullException`

### API
- `SensorAPI`: Пример клиента, использующий `RestTemplate` для регистрации сенсора и отправки данных.

## Установка и запуск
Для запуска приложения вам нужно:
1. Создать базу данных и настроить её в `application.properties`.
2. Использовать Maven или Gradle для сборки проекта.
3. Запустить `SpringRestMyappApplication`.

## Использование
- **Регистрация сенсора**: Отправьте POST запрос на `/sensors/registration` с данными сенсора.
- **Добавление метеоданных**: Отправьте POST запрос на `/measurements/add` с данными о погоде.
- **Получение всех данных**: GET запрос на `/measurements/`.
- **Получение количества дождливых дней**: GET запрос на `/measurements/rainyDaysCount`.
